# Frozen D3 starting contract

The existing dependency-free Rust CLI reads UTF-8 commands from stdin. Blank lines
are ignored. `add ACCOUNT SIGNED_I64` adjusts an account; balances cannot be negative.
Accounts are nonempty tokens. Output is account TAB decimal balance LF, sorted by
account string. Invalid command/input/arguments return exit 2 with useful stderr
and no stdout. Existing parser/add/report behavior must remain supported.

Follow-up tasks add transfer/batch atomicity, durable atomic state, then dry-run.
Do not implement later tasks early. Do not edit this file or original tests.
